# Game of Fate — runner

Standalone mobile tap-to-jump game. Canvas perspective track, a runner, eight emoji temptations, one point per cleared obstacle, K.O. and restart. Personal record stays in localStorage when supported. Space or Up also jumps. Leaving the tab pauses play.

No dependencies or backend. Run `npm test` for deterministic physics and collision tests; serve `dist/` as a static website. This is separate from the profile website and countdown.
